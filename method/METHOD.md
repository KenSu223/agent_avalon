# 先验受控的记忆评测方法：规格说明 v1.0

工作名称：**PCME（Prior-Controlled Memory Evaluation）**。论文里的正式名称由 PI 决定。
写于 2026-10-10，对应 PLAN.md 第 1 步。§6 列出的性质检验属于**预先登记**：本文件在相应实验运行之前提交，提交时间就是登记时间。之后若有任何修改，都记在 §9 的变更记录里。

---

## 0. 要解决的问题

agent 记忆基准的标准做法是：系统读入一段历史，之后回答关于这段历史的问题，最后报告答对的比例。这个比例混合了两种来源：
1. 记忆里确实保留了证据，读题模型据此答对；
2. 记忆里没有证据，但答案"合理"，读题模型凭自身先验猜对。

我们已有的证据表明，第 2 种来源的占比在现有基准上为 7%–63%（FINDINGS §8），而且随系统变化（例如放弃作答的倾向不同，见 §12）。因此原始准确率既**抬高了记忆差的系统**，又**可能打乱系统之间的排名**。

PCME 的目标是**把"记忆贡献"和"先验贡献"分开测量**，并且做到四点：
- 每个指标都有明确的估计对象；
- 写清楚每个指标依赖哪些假设；
- 每条假设都有可以执行的诊断检验；
- 可以直接套用到任何现成的问答式记忆基准上。

适用范围：答案可以用官方评分器判对错的记忆问答基准，例如 LongMemEval、LoCoMo、MemoryAgentBench，以及我们自建的 C/I 条目。偏好遵循类基准（例如 PrefEval）没有"闭卷猜中"的对应概念，只做描述性报告（§8）。

## 1. 设定与记号

| 记号 | 含义 |
|---|---|
| i = 1..N | 基准里的题目，分为可回答题 𝒬⁺ 和不可回答题 𝒬⁻（例如 LoCoMo 第 5 类、LongMemEval 中带 `_abs` 的题） |
| u(i) | 题目 i 所属的对话或文档（即 episode），也是自助法的聚类单位 |
| s | 记忆系统。读入历史后，对每道题返回一段上下文 c_si |
| f | 读题模型（底座）。所有系统共用同一个模型、同一套 prompt、同样的解码设置（T=0） |
| π | 作答协议：π_A 为原生协议（不禁止放弃作答，即现有 `ANSWER_SYS`）；π_F 为强制作答（"即使记忆里没有，也给出最可能的答案"） |
| J | 基准官方的评分器 |
| Y_si^π ∈ {0,1} | 系统 s 在题 i、协议 π 下是否答对；评分为 [0,1] 连续值时，下面所有定义按期望照样成立 |
| ∅ | 空上下文，即闭卷 |
| Z_si ∈ {0,1} | 潜变量：c_si 是否包含答题所需的证据 |

**两状态模型**（假设 A1，§3）：
- 有证据时（Z_si = 1），读题模型以概率 p_i 答对，p_i 称为读题保真度；
- 无证据时（Z_si = 0），读题模型以概率 h_si 答对，h_si 称为该上下文下的猜中率。

由此得到

  E[Y_si] = R_si · p_i + (1 − R_si) · h_si，其中 R_si = P(Z_si = 1)，即保持率。

我们感兴趣的是 R_si（记忆是否保留了证据）。原始准确率测到的却是上面的整个和式。

## 2. 估计对象

### 2.1 逐题先验猜中率 g_i
g_i ≡ P(Y_i^{F,∅} = 1)：在强制作答、闭卷条件下，读题模型 f 答对第 i 题的概率。概率取自两个来源：解码随机性，以及一组无关的 prompt 变体。

- **为什么必须用 π_F 估计**：在 π_A 下，闭卷模型几乎总是放弃作答（FINDINGS §8 的 natural 协议），估出的 g 接近 0。但真实系统的上下文不为空，读题模型可能照样猜。所以 π_A 下的"闭卷猜中率"并不是有上下文时的猜中率（见 §3 的 A2）。
- **v1.2 修改**：用于 PCS / MA 的 ĝ_i 必须使用**评测时完全相同的 prompt 和题面**（上下文为 "(nothing)"）来抽取。下面列出的闭卷 prompt 变体只用于分层（§2.2）。理由见 FINDINGS §13.2 第 2 点。
- **估计方法**：对读题模型做 K 次闭卷抽取，ĝ_i 为答对次数的平均。第 1 步采用 K = 6，均使用同一个评判模型和官方评分器：
  1. 原有的强制 prompt（`FORCED_SYS`），T = 0（已有数据）；
  2. 改写版强制 prompt F1，T = 0；
  3. 不带 system prompt、只有用户轮的强制 prompt F2，T = 0；
  4. 原有强制 prompt，T = 1.0，抽 3 次（sample_idx 为 1–3）。
- g_i 只对**特定读题模型**有意义。系统比较时用的是同一读题模型（Qwen3-235B）的 ĝ_i。

### 2.2 先验分层
- **抗先验题** 𝓡 = {i ∈ 𝒬⁺ : 所有参考模型的所有闭卷抽取都答错}。参考模型包括读题模型 Qwen3-235B 的全部 K 次抽取，以及另一家族 Llama-3.3-70B 的 T=0 强制抽取。
- **可被先验答对的题** 𝓐 = 𝒬⁺ \ 𝓡。
- 取并集是为了让 𝓡 偏保守：只要有任何一个参考模型能猜中，这道题就不算抗先验。
- 分层依赖的假设是 A4。我们用"泄漏率"检验它（性质检验 P1(ii)），并对分层方式做敏感性分析（P6）。

### 2.3 反先验保持率 CPR（主指标）
  CPR_s^π = (1/|𝓡|) Σ_{i∈𝓡} Y_si^π

- **识别**：只需要 A4，即对 i ∈ 𝓡，闭卷猜中率约为 0。此时 E[Y_si] = R_si·p_i + (1 − R_si)·h_si。其中 h_si 是"无证据但有其他记忆内容时"的猜中率；如果非证据内容能帮助推断答案，那份帮助本身就来自记忆，计入记忆是合理的。
- **含义**：记忆保留下来、并且被读题模型用上的"无法靠猜得到"的信息所占的比例。
- **协议**：在任何协议下都可以计算，因为在 𝓡 上猜测几乎得不到分。预测它对协议基本不敏感（P7）。
- **相对版本**：如果有 oracle 系统（§6 P2），报告 CPR_s / CPR_oracle，用来扣除读题难度。

### 2.4 记忆贡献分 MA 与先验校正分 PCS（只在 π_F 下定义）
  MA_s  = (1/|𝒬⁺|) Σ_{i∈𝒬⁺} (Y_si^F − ĝ_i)
  PCS_s = Σ_{i∈𝒬⁺} (Y_si^F − ĝ_i) / Σ_{i∈𝒬⁺} (1 − ĝ_i)
  ORS_s = Σ_{i∈𝒬⁺} (Y_si^F − ĝ_i) / Σ_{i∈𝒬⁺} (Y_oracle,i^F − ĝ_i)

- **MA**（memory-attributable accuracy）：相对读题模型自身的猜测，记忆额外带来了多少准确率，单位是准确率点数。
- **PCS**（prior-corrected score）：MA 除以可提升空间 mean(1 − ĝ)。
  - 在 A1 + A2 下、并且 p_i = 1 时，PCS = Σ R_si(1 − g_i) / Σ(1 − g_i)，即按"不可猜程度"加权的保持率。
  - 再加上 A3 时，PCS 等于平均保持率 R̄_s。
  - 它就是心理测量学里经典的"猜测校正"公式 (acc − g)/(1 − g) 的逐题加权推广。
- **ORS**（oracle-referenced score）：当读题保真度 p_i < 1 时，两状态模型下逐题的 R_si = (E[Y_si] − g_i)/(p_i − g_i)。ORS 是这个量按 (p_i − g_i) 加权的聚合估计。只有存在 oracle 系统时才报告。
- **为什么不在 π_A 下定义**：π_A 下的 h_si 取决于每个系统上下文触发的放弃作答倾向，不等于 g_i，A2 不成立。π_A 下只报告 CPR、分层表和放弃作答指标。
- **与退化情形的关系**：如果 ĝ_i ∈ {0,1}（例如只用一次 T=0 抽取），PCS 的分子由两部分组成：𝓡 上的答对数，减去 𝓐 上答错的数目（即先验干扰，见 2.6）。这说明 PCS 和 CPR 的差别正好来自 𝓐 上的干扰。

### 2.5 先验虚高 PI
  PI_s = Acc_s^F − PCS_s

- 在 A1–A3 下、p = 1 时，PI_s = (1 − R̄_s)·ḡ：记忆越差，被先验抬高得越多，导致系统之间的差距被压缩。
- 框架实验里原来使用的"C 题准确率 − 真实保持率"（`framework_study/results/inflation.txt`）是受控设计下的特例，以后改称"一致题虚高"，以免和这里的一般定义混淆。

### 2.6 逐题 2×2 分解（描述性，只依赖分层本身）
| | Y = 1 | Y = 0 |
|---|---|---|
| i ∈ 𝓡 | **已核实记忆**（verified memory） | 记忆失败 |
| i ∈ 𝓐 | **无法核实的得分**（可能来自记忆，也可能是猜中） | **先验干扰**：读题模型闭卷都能猜中，系统却答错了，原因可能是放弃作答，也可能是上下文误导 |

- 各格都以占 |𝒬⁺| 的比例报告，Acc = 已核实记忆 + 无法核实的得分。
- **已核实比例** = 已核实记忆 / Acc，即系统的得分中有多少能确认来自记忆。
- 在 π_A 下，先验干扰主要来自放弃作答，这正是 FINDINGS §12 发现的排名混淆的来源。

### 2.7 不可回答题：只单独计分，不与可回答题合并
- 在 π_A 下，用评判模型判断每个回答是否属于放弃作答（abstain）。实现方法见 §4 S3。
- 指标：
  - 正确放弃率 CA = P(abstain | 𝒬⁻)；
  - 错误放弃率 FA = P(abstain | 𝒬⁺)；
  - 区分度 J = CA − FA（Youden 指数）。
- **规则**：不可回答题的分数**不得**与可回答题平均成一个总分，必须和 CPR（或 PCS）一起作为二维结果报告。
- 理由：什么都不记的系统对所有题都放弃作答，CA 和 FA 都高，所以 J ≈ 0，不会拿到分。用原始准确率计分则不同：LoCoMo 第 5 类会奖励遗忘（FINDINGS §11，Aider 得 0.86，而 Raw RAG 只有 0.55）。

### 2.8 受控 C/I 成对条目（反先验区间的直接测量）
- **设计**：同一个槽位、同一个问题，C 版本（符合先验）和 I 版本（违背先验）只有槽位取值不同；每个用户分到哪个版本是随机的。题目难度等固定效应由此在 C/I 对比中抵消。真实基准的分层对比做不到这一点：𝓡 和 𝓐 的题目在类型和难度上都可能不同。
- **指标**（每个系统、每个检查点）：
  - 保持率 R^v = P(记忆状态 = RETAINED | 版本 v)，由两个评判模型标注，只计两者一致的条目；
  - 保持率差 ΔR = R^C − R^I：先验导向删除的直接测量，同时用来检验 A3；
  - 翻转不对称 ΔF = F^I − F^C：记忆文本被改写成符合先验版本的程度；
  - 信念准确率 K^v = P(强制选择探针答出原版本 | v)；
  - 信念差距 ΔK = K^C − K^I：受控设计下的先验虚高；
  - 反先验保持率：K^I 和 R^I；
  - 机制分解：P(KEPT | 记忆状态, 版本)。
- C/I 条目的 g_i 由 V1 估计：g_C = p_congruent，g_I = 1 − p_congruent，均为 20 次 T=1 抽取的结果。

## 3. 识别假设，以及每条怎么检验

| 编号 | 假设 | 哪些指标需要它 | 怎么诊断 |
|---|---|---|---|
| A1 | 两状态模型：结果只取决于证据在不在，以及猜中率 | MA、PCS、ORS 的"保持率"解释 | P2（oracle）、P4（与真实保持率对照） |
| A2 | 上下文中立地猜：π_F 下，无证据的上下文不改变猜中率，即 h_si ≈ g_i | MA、PCS、ORS | **P3**：证据消融；在框架实验中检查被删条目的信念 |
| A3 | 保持与可猜性无关：R_si 与 g_i 不相关 | 只有"把 PCS 解释为整体保持率"时需要。CPR 不需要它 | C/I 保持率差 ΔR（受控设计里可以直接检验）。在真实基准上，用"上下文是否含标准答案"作为代理，按层比较 |
| A4 | 先验探测器有效：𝓡 里的题，闭卷确实猜不中 | CPR、2×2 | **P1(ii)**：在独立样本上测泄漏率；P6 敏感性分析 |
| A5 | 评判稳定：同一评判模型、同一官方评分器 | 全部指标 | 评判模型固定。人工校验由 PI 团队完成，之前只报告两个评判模型之间的一致性 |

**依赖关系的要点**：CPR 只需要 A4，是假设最少的主指标；PCS 用到全部题目，但需要 A2，而 A2 只可能在 π_F 下成立。这就是"统一作答协议"成为标准流程第 2 步的原因。

## 4. 标准流程（四步）

**S1 估计先验**
- 对每道可回答题，用评测所用的读题模型做 K 次闭卷强制抽取（prompt 变体 × T=0，加上若干 T=1 抽取），另外至少用一个其他家族的模型抽取 1 次。
- 用官方评分器打分，输出 ĝ_i 和分层 𝓡 / 𝓐。
- 报告该基准中"可被先验答对"的比例，附 95% 置信区间。

**S2 统一作答协议**
- 把每个系统对每道题返回的上下文原样保存。
- 在 π_F（可回答题）和 π_A（全部题）两种协议下分别作答。读题模型、解码设置（T=0）和评判模型对所有系统完全一致。
- 保留原始输出。

**S3 打分**
- CPR：任何协议均可，作为主指标。
- MA、PCS、PI、ORS：只在 π_F 下计算。
- 2×2 分解：π_F 和 π_A 下各做一次。
- 不可回答题：在 π_A 下计算 CA、FA、J。
  - 放弃作答的判定用 LLM 评判模型（gpt-oss-120b，固定 prompt：回答是否拒绝或声明没有该信息，yes/no）；
  - 现有正则 `ABS` 作为交叉核对，报告两者一致率。
- 排名分析见 §5。

**S4 反先验探针**
- 把 C/I 成对条目嵌入历史中。
- 用两个评判模型标注记忆状态，用强制选择题探测信念。
- 报告 ΔR、ΔF、ΔK、K^I，并做机制分解。

## 5. 统计推断
- **主方法**：按题目配对的自助法（B = 2000，seed = 0，取百分位区间）。所有系统使用同一组重抽样下标，所以系统之间的差异是配对估计。
- **推断条件**：推断以基准中给定的那几段历史为条件。MemoryAgentBench 的 RULER-QA1 只有 1 个 episode，只能按题目做推断；我们会把这一点写明。
- **LoCoMo 的聚类稳健性**：按对话聚类做自助法，作为敏感性分析。共只有 10 个聚类，区间偏宽，结果仅供参考。
- **框架实验**：按用户聚类做自助法，与现有分析一致。
- **ĝ 的不确定性**：提供两阶段自助法作为选项：先重抽题目，再在每道题内部重抽 K 次闭卷结果。报告区间是否因此改变。
- **排名一致性**：Kendall τ_b（处理并列）和 Spearman ρ，置信区间来自配对自助法。
- **两两系统比较**：
  - 用配对的符号翻转置换检验（10⁴ 次），并做 Holm 校正；
  - 效应量以准确率点数报告；
  - **"确认的排名反转"**：一对系统，在原始准确率上的差异和在 CPR（或 PCS）上的差异，95% 置信区间都不含 0，并且方向相反。只有一方满足的，计为"未定"。
- **等价检验**：判断"约等于 0"时使用 TOST，要求 90% 置信区间完全落在 ±δ 之内。δ 预先设定为 0.03，理由是它小于我们打算解释的最小系统差异（0.05）的一半以上。每个等价检验的结果分三种，**事先约定都如实报告**：
  - "等价"：90% 置信区间完全落在 ±δ 之内；
  - "不等价"：95% 置信区间不含 0，且点估计超出 ±δ；
  - "无法判定"：其他情况，通常是样本量不够。

## 6. 预先登记的性质检验（对应 PLAN 1.3）

公共设置：
- 读题模型 Qwen3-235B（T=0）；
- 评判模型 gpt-oss-120b，LoCoMo 使用 LongMemEval 的通用判题 prompt，MemoryAgentBench 使用子串精确匹配；
- 数据：LoCoMo 第 1–4 类，以及 MemoryAgentBench RULER-QA1 + QA2（两者各 100 题）；
- ĝ 和分层按 §2.1–2.2（K = 6，加上 Llama 的 T=0 抽取）；
- 读题时用的 π_F prompt 与估计 ĝ 时用的所有 prompt 都不同，所以样本是独立的。

**参照系统**（新增，都是规则构造，不调用记忆框架）：
- **Empty**：上下文为 "(nothing)"，与 rescore 中上下文为空时的输入完全相同。
- **Oracle**：只给标准证据。
  - LoCoMo：按 `evidence` 字段中的 dia_id 取出对应轮次，格式为 "[日期] 说话人: 内容"，按时间排序。evidence 无法解析的题不进入涉及 Oracle 和 BM25 的分析，并报告剔除数目。
  - MemoryAgentBench：先把文档按 rescore 的方式切成 1000 词一块；在包含任一标准答案字符串（规范化后）的块里，取与问题 BM25 得分最高的那一块。找不到这样的块的题剔除，并报告数目。
- **BM25+ev**：对全部轮次（LoCoMo，k = 10）或全部块（MemoryAgentBench，k = 3）做 BM25 检索，强制包含证据：证据轮次或证据块替换排名最低的非证据项。之后按时间顺序排列。
- **BM25−ev**：同样的检索，但去掉证据（LoCoMo 去掉 evidence 轮次；MemoryAgentBench 去掉所有含标准答案字符串的块），k 保持不变。

### P1 下限（零点校准）
- 系统：Empty，π_F。在 LongMemEval、LoCoMo、MemoryAgentBench 三个基准上分别检验。
- 预测：
  1. 在每个基准上，MA_Empty 的 90% 置信区间落在 ±0.03 之内（TOST）；
  2. **泄漏率** CPR_Empty 的 95% 上界 ≤ 0.03；
  3. 作为描述性对照：原始 Acc_Empty^F 在 LoCoMo 上 ≥ 0.10。这说明原始准确率有一个非零的"地板"，而 MA 把地板移回了 0。
- 判定规则：
  - 若 (1) 不成立，说明 ĝ 与评测 prompt 不匹配，标准流程改为"用评测 prompt 本身做闭卷抽取来估计 g"，并记入变更记录；
  - 若 (2) 不成立，增加抽取次数或参考模型，直到泄漏率 ≤ 0.03，同时报告修改前后的结果。

### P2 上限（抗先验题给了证据就能答对）
- 系统：Oracle，π_F。
- 预测：
  1. 在每个基准上，CPR_Oracle 的 95% 下界 ≥ 0.50。这样真实系统在 𝓡 上得分很低时，原因是记忆，而不是题目太难；
  2. 动态范围：PCS_Oracle − PCS_Empty ≥ 0.50；
  3. 报告难度差 Δ_Oracle = Acc_Oracle(𝓐) − Acc_Oracle(𝓡)。
- 判定规则：若 Δ_Oracle 的点估计 > 0.10，说明分层与题目难度混在一起。此时真实系统的分层对比要同时报告 oracle 归一化的版本，即 CPR_s / CPR_Oracle 对比 Acc_s(𝓐) / Acc_Oracle(𝓐)，以及 LoCoMo 按类别分别的结果。

### P3 上下文中立地猜（A2，关键识别假设）
- 系统：BM25−ev，π_F。
- 统计量：D = mean_i (Y_i − ĝ_i)，只在"干净缺失"的题上计算，即上下文里不含任何标准答案字符串（规范化后子串匹配）的题。
- 预测：
  1. **MemoryAgentBench**：|D| ≤ 0.05（TOST，90% 置信区间）。QA1 + QA2 中"干净缺失"的题预计只有 150 道左右，结果可能是"无法判定"；如果是，就如实报告为无法判定，并以框架实验的检验（第 3 项）为主；
  2. **LoCoMo**：D ≥ −0.03（单侧，95% 下界），即非证据上下文不压低猜中率。同时报告 D 本身：D 为正，说明对话中别处也提到了答案。这种冗余提供的信息本身就来自记忆，是合理的。
  3. **框架实验**（不需要新开销）：对被标为 DROPPED 的条目，比较 P(信念为符合先验的选项) 与这些条目 V1 的 p_congruent 的平均值。预测在强压缩模型（Qwen3-235B）的系统上合并计算时 |D| ≤ 0.05，每个系统的结果单独列出。
- 判定规则：若 π_F 下 A2 不成立，PCS、MA、ORS 不作为真实系统的保持率估计来报告；方法退回到只用 CPR，并记录这一点。
- 补充（不属于第 1 步）：π_A 下的同一检验放到第 2 步做，预测是 π_A 下 D 显著为负。

### P4 与真实保持率对照（框架实验，不需要新开销）
- 单元：框架 × 检查点（检查点 ≥ 2），包括 Qwen3-235B 和 Qwen3-8B 两组运行；每个单元合并 C、I 两个版本。
- 真值 R_cell：RETAINED 的比例（只计两个评判模型一致的条目）。
- 原始分 Acc_cell：KEPT 的比例。
- PCS_cell：g 取自 V1（Qwen3-235B，即答题模型），探针本身就是强制选择，相当于 π_F。
- 预测：
  1. MAE(PCS, R) < MAE(Acc, R)，按用户自助法计算两者之差的 95% 置信区间，区间不含 0；
  2. Pearson r(PCS, R) > r(Acc, R)，同样给出自助法置信区间。
- 同时报告：
  - 对照 R^I 的结果；
  - raw_history（完整历史，R ≈ 1）的 PCS，作为框架实验中的上限检验；
  - 弱压缩模型那组运行中 ΔR > 0 的单元，用来展示 A3 不成立时 PCS 的偏差方向。

### P5 已知保持率下的恢复（示意，不作为证据）
- 做法：按保持率 r ∈ {0, 0.1, …, 1}，逐题混合 BM25+ev 和 BM25−ev 两组真实回答。三种机制：
  1. 随机删除（A3 成立）；
  2. 优先删可猜的题；
  3. 优先删不可猜的题。
- 报告 Acc、CPR、PCS、ORS 随 r 的变化。
- 标注为示意：它在真实回答上展示各估计量在 A1–A3 下的行为，以及 A3 不成立时原始准确率如何"奖励删掉可猜的题"。

### P6 对先验估计方式的敏感性（对应 PLAN 1.3(d)）
- 比较五种分层定义：
  - D1：Qwen 单次 T=0（旧）；
  - D2：Llama 单次 T=0；
  - D3：两者并集，T=0（目前论文中的数字）；
  - D4：Qwen 全部 6 次抽取；
  - D5：D4 加 Llama，**作为今后的主定义**。
- 计算现有 11–12 个系统（π_A 数据）的 CPR 排名在各定义之间的 Kendall τ_b。
- 预测：LoCoMo 上 D3 与 D5 之间 τ_b ≥ 0.8。MemoryAgentBench-QA1 的 𝓡 约 50 题，只报告 τ 及其置信区间，不设门槛。
- 同时报告各定义下"可被先验答对"的比例（审计数字的敏感性）。
- 判定规则：若 τ_b < 0.8，论文以 D5（最保守）为主定义，其余放附录，并在正文说明排名对估计方式敏感。

### P7 协议不变性（对应 PLAN 1.3(e)，第 2 步完成后执行，预测现在登记）
- 预测：
  1. 对每个系统，0 ≤ CPR^F − CPR^A ≤ 0.05。π_F 下读题模型在证据不确定时也会作答，所以 CPR 只可能小幅上升；
  2. Acc^F − Acc^A 在系统之间差异很大，且与 π_A 下的放弃作答率正相关；
  3. Acc^F 的系统排名比 Acc^A 的排名更接近 CPR 的排名（Kendall τ 之差的自助法置信区间 > 0），在 MemoryAgentBench-QA1 上尤其明显。

## 8. 局限（在论文中如实写明）
- g_i 依赖读题模型。换底座就要重新估计，这正是 S1 必须使用评测所用读题模型的原因。
- 分层并不等于随机分组：𝓡 和 𝓐 在题型和难度上可能不同。我们用 P2 的难度差来量化，用 C/I 受控设计来补足。
- LoCoMo 的 evidence 标注本身有噪声，而且对话中常有冗余，所以 Oracle 和证据消融只是近似。
- 评判模型的宽严会同时影响 g 和 Y。两者使用同一个评判模型，影响方向一致，但不会完全抵消。
- 偏好遵循类基准没有闭卷猜中的对应概念，只能做描述性报告（例如什么都不记时的遵循率）。
- 推断以给定的历史为条件；MemoryAgentBench 的 RULER-QA1 只有 1 个 episode。
