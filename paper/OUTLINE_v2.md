## 标题候选
1. *Your Memory Benchmark Is Measuring the Prior*
2. *Remembering vs. Guessing: Prior-Controlled Evaluation of Agent Memory*
3. *Guessing Is Not Remembering: Separating Memory from Prior Knowledge in Agent Memory Evaluation*

## 一句话
现有的 agent 记忆基准把"凭先验猜对"也算成"记住了"；我们提出一套评测方法，把记忆的贡献和先验的贡献分开测量。用这套方法审计和重新打分现有基准后，结论会发生变化。

## 贡献（贡献类型：评测方法，不是新的记忆方法）
1. **问题**：在 4 个主流基准上，读题模型不看历史也能答对相当一部分题。期望猜中率在 LoCoMo 为 0.149，在 LongMemEval 为 0.133，在 MemoryAgentBench-QA1 为 0.353（FINDINGS §13.2 第 8 点）；"至少猜中一次"的比例为 29–54%。
2. **方法（PCME）**：
   - 逐题估计先验，用两个模型家族、多次抽取；
   - 主指标是抗先验题上的 CPR；
   - 在强制作答协议下计算猜测校正分 PCS；
   - 不可回答题单独计分（区分度 J）；
   - 用 C/I 受控条目测量反先验的区间。
   - 每条识别假设都有对应的诊断检验，每个指标都经过预先登记的性质检验（METHOD.md；FINDINGS §13）。
3. **审计与重新打分**：12 个记忆系统（4 个库系统、6 个产品级压缩 prompt、2 个基线）在 LoCoMo 和 MemoryAgentBench 上重新打分。
   - MemoryAgentBench-QA1 上，9/11 个系统的 CPR ≤ 0.04（§11）。原始分 0.15–0.35 的差距来自放弃作答率（§12）。
   - LoCoMo 第 5 类奖励遗忘（§11）。
   - 协议对照的结果待第 2 步完成。
4. **机制**（受控实验，12 个系统 × 43 个用户 × 4 个检查点）：
   - 记忆删除并不区分符合先验与违背先验的内容；
   - 但删掉之后，读题时先验会把空缺补回来，信念差距最大达 +0.96（Aider）；
   - 改写的范围决定丢失多少：局部更新稳定，整份重写丢失大部分内容（§1–§2、§9、§10）。

## 章节结构
1. **Introduction**
   - 例子：Aider 的记忆保留了 0% 的条目，在符合先验的题上却答对 97%（§1）。
   - 为什么这个问题会影响结论：同一个底座模型并不能抵消先验，因为各系统放弃作答的倾向不同（§12）。
   - 贡献列表。
2. **Related work**
   - 记忆基准：LongMemEval、LoCoMo、MemoryAgentBench、PrefEval、PersonaMem(-v2)。
   - "先找到证据再判分"一类做法：Ground Truth First、MemGym、100-LongBench（§7）。
   - 心理测量学里的猜测校正、高阈值模型。
   - 认知科学：Bartlett 的系列再现，以及迭代学习（作为动机，一段即可）。
   - 记忆系统：Mem0、LangMem、Nemori 等。
3. **Problem formulation**
   - 两状态模型；
   - 估计对象（g_i、CPR、MA / PCS / ORS、PI、2×2 分解、J）；
   - 识别假设 A1–A5，以及每条的诊断方法（METHOD §1–§3）。
4. **PCME procedure**
   - 四步：估先验 → 统一作答协议 → 打分 → C/I 探针。
   - 统计推断方法（METHOD §4–§5）。
   - **第 1 步得到的方法要点**：
     - g 必须用评测时完全相同的 prompt 来估计；
     - 只靠指令做不到强制作答。
5. **Validating the metrics**（第 1 步的性质检验）
   - P1 下限、P2 上限与可解性、P3 上下文中立地猜、P4 与真实保持率对照、P6 敏感性；
   - P5 示意图（FINDINGS §13）。
6. **Auditing and re-scoring existing benchmarks**
   - 各基准可被先验答对的比例；
   - 12 个系统在三种协议下的结果；
   - 排名分析（只报告"确认的排名反转"）；
   - 不可回答题的区分度（第 2 步，待）。
7. **Controlled counter-schema probes**
   - C/I 数据集与生成流程（第 3 步，待）；
   - 机制结果，包括换一个模型家族的复现（第 4 步，待）。
8. **Discussion**：给基准设计者和记忆系统开发者的建议
   - 报告 CPR；
   - 统一作答协议；
   - 不可回答题单独计分；
   - 局部更新式的记忆设计。
9. **Limitations**
   - g 依赖读题模型；
   - 分层不是随机分组；
   - LoCoMo evidence 标注有噪声；
   - 评判模型；
   - 人工校验待完成；
   - 偏好类基准只能做描述性报告。

## 风险与应对
- **与 PersonaMem-v2 等工作撞车**（§7）：我们的区别在于审计现有基准、对真实系统重新打分、同一槽位的 C/I 成对条目，以及经过性质检验的指标。
- **"只是换了个算法"**：方法部分要突出识别假设和诊断检验，并如实报告失败过的版本（v1.0）。这正是方法严谨的证据。
- **审稿人质疑评判模型**：人工校验 150 条，需要 PI 团队完成，不能编造。
- **样本量**：MemoryAgentBench 每个子集只有 100 题，所以只报告确认的反转，并写明未定的数量。
