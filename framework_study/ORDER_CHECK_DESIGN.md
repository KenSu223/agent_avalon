## 1. 要回答的问题
- 条目被删掉以后，读题模型拿到的上下文里没有这个条目。这时 ΔK = P(选 C | C 版本) + P(选 C | I 版本) − 1，在不含条目信息时化简为 2·P(选 C) − 1。
- P(选 C) 有两个来源：先验（C 符合常识），以及首选项偏好（C 总在第一个）。step 4 的设计把两者完全混在一起。
- 本检查把顺序反过来，估计两者各占多少。

**分解。** 记 a_O、a_R 为原顺序和反序下、被删条目上选 C 的比例。
- 位置成分 π = (ΔK_O − ΔK_R) / 2 = a_O − a_R：把 C 从第一位挪到第二位，选 C 的比例下降多少。
- 顺序平衡后的信念差距 ΔK_B = (ΔK_O + ΔK_R) / 2 = 2·ā − 1，其中 ā 是两种顺序下选 C 比例的平均。这是去掉首选项偏好以后归于先验的部分。
- 读法：
  - 纯先验：π = 0，ΔK_R = ΔK_O；
  - 纯首选项偏好：ΔK_R = −ΔK_O，ΔK_B = 0；
  - 位置占比 = π / ΔK_O。

## 2. 假设与预测（定稿时固定）
- **H1（论文的解读）**：删除后的作答由先验决定。
  - 预测：两个家族下，删除率 ≥ 0.5 的系统合并后 π 的 95% 置信区间上界 ≤ 0.05，且 ΔK_R ≥ 0.8。
  - 理由：V1 门槛要求两种选项行顺序平均后 P(C) ≥ 0.8，由此可推出 I 在前时 T=1 下的 P(C) ≥ 0.6 > 0.5，即没有上下文时首选项偏好翻转不了众数答案。
  - 但这个推论只覆盖没有上下文、T=1 的情形；记忆上下文中、T=0 下不一定成立，所以要实测。
- **H2（位置贡献）**：π > 0，且置信区间不含 0。
- **无先验对照的预测**：
  - Llama 下 P4.5 的失败（ΔK = +0.435）至少部分来自首选项偏好，即 |ΔK_B| < |ΔK_O|；
  - Qwen 下 ΔK_O = −0.116，不预测方向。
- **其他预测**：
  - P4.6（更新违背先验时更容易退回旧值）在反序和顺序平衡下仍然成立，置信区间不含 0；
  - P4.7（MAE(PCS, R) < MAE(原始准确率, R)）在反序和顺序平衡下仍然成立。

## 5. 判定规则（定稿时固定）以及对论文的影响
**E1（主检验）**
- **D1，可以忽略**：两个家族合并后 π 的置信区间上界都 ≤ 0.05，且每个删除率 ≥ 0.5 的系统 |π| ≤ 0.05。
  - 论文中的 ΔK 数字不变。
  - 可以加一句话，说明在顺序平衡的检查下结论不变。
- **D2，小但不可忽略**：不满足 D1，也不满足 D3。
  - 论文的 ΔK（`tab_step4`、`fig_readtime`、宏 `\dKrwQwenLo/Hi`、`\dKrwLlamaLo/Hi`，摘要里的 `\dKrwQwenHi`）改为顺序平衡的 ΔK_B，来自 E4b；
  - 加一句话说明 step 4 的探针是 C 在前，以及做过平衡检查；
  - 定性结论（"被删的条目由先验补回"）不变。
- **D3，实质性**：任一家族合并后 π > 0.15，或者 codex、aider、anthropic_api 中任一系统在任一家族下 ΔK_B < 0.5。
  - "deleted items are answered from the prior" 必须改写为同时量化先验和位置两部分；
  - 摘要和 `controlled.tex` 的结果段都要改；
  - 改论文之前先报告 PI。

**E2（无先验对照）**，每个家族分别判定：
- **N-pos**：|ΔK_B| ≤ 0.10 而 |ΔK_O| > 0.10。P4.5 的失败归因于选项位置，`controlled.tex` "A failed control" 一段中"option labels happen to be unbalanced"的解释要改成位置解释。
- **N-label**：|ΔK_O − ΔK_R| ≤ 0.10。位置解释不了，原有的标签内容解释保留。
- **N-mixed**：其他情况。两种解释都要写。
- 只有 10 个条目、140 行，置信区间会很宽，这一点照实写。

**E3（PCS 校准）**
- R 和 B 下都满足 MAE(PCS) < MAE(acc)，则 P4.7 稳健。
- B 下的 MAE(PCS) 与 O 相差 ≥ 0.005 时，论文里的 `\pcsMaeQwen`、`\pcsMaeLlama` 改为 B 的数值，否则不变。

**E4a（P4.6）**
- 在 B 下置信区间仍不含 0，则结论保留。
- 数值 `\updQwen`、`\updLlama` 与 B 相差 ≥ 0.03 时改为 B 的数值。

E0 和 E5 是探索性的，不触发论文改动。
