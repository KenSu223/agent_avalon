## 1. 组成（候选约 600 对，过门槛后的目标约 500 对）
| 类型 | 候选数 | 说明 |
|---|---|---|
| rule（规则） | 约 300 | Sam 的工作环境里某个事物"怎么运作"的反常识事实，分布在约 12 个领域：软件工具、办公设施、流程、制度、硬件设备、差旅物流、财务报销、人事、厨房餐饮、安全、日程与时间、通讯 |
| procedure（流程） | 约 80 | 把常规步骤顺序倒过来 |
| preference（偏好） | 约 80 | 格式或沟通方式的偏好。C 是常见惯例，I 是少见但真实存在的做法；两个版本都是明确、可执行的指令 |
| update（知识更新，新增） | 约 80 | 先在一个会话里说出旧值，再在之后的会话里更新为新值，问的是现在的值，见 §2.3 |
| neutral（无先验对照，新增） | 约 40 | 两个选项都不符合常识，先验约为 0.5，用来测量没有先验干扰时的保留率，见 §2.4 |

## 2. 编写规则（构建脚本自动检查的规则以 G0 标出）
### 2.1 所有类型通用
1. **只换关键词**（G0）：rule、procedure、update 三类的 C 句和 I 句，词集合的 Jaccard 重合率 ≥ 0.4。
2. **不加任何提示词**（G0）：不出现 actually、surprisingly、strangely、oddly、weirdly、believe it or not、unusual、in fact、counterintuitively、weird、funny enough，也不出现 because 之类的理由从句。
3. **问题是二选一**：两个选项就是槽位的两个取值，写成大写的短词。问题本身不能暗示答案。
4. **事实是顺带说出的**：每条都配一个与事实无关的 task（Sam 请 Atlas 帮忙做的事）和 reply（Atlas 的回答），reply 绝不复述这个事实。偏好类条目像原来一样，配一个无关的小问题作为铺垫。
5. **话题唯一**（G0）：每条有一个 `topic` 键，整个数据集里不重复，避免同一个用户分到两条会互相干扰的条目。
6. **世界设定一致**：Sam 在 Veltrix 工作，公司位于 Northvale 镇的 Harbor Building；助手名叫 Atlas。
7. **I 版本必须能作为"本地约定"成立**：不能是物理上不可能的事，尽量少写会被模型当作错误主动纠正的内容（S02、S08 就是这样被淘汰的）。
8. **标注 `normative`**：C 版本是规范或最佳做法、I 版本是坏做法的条目，标为 true。分析时作为分层变量，像原来一样处理。

### 2.2 偏好（preference）
保留原有格式：`lead + clause`，可选字段 `probe_task` 和 `behaviour_regex` 用于行为探针。新条目可以只给二选一的问题。

### 2.3 知识更新（update）
- 字段 `initial` 是旧值所在的句子，`C.clause` 和 `I.clause` 是更新句。每个版本都有自己的旧值和新值：
  - **C 版本**：旧值违背常识，更新后变成符合常识的值。也就是说，更新的方向与先验一致。
  - **I 版本**：旧值符合常识，更新后变成违背常识的值。这时先验和过时的记忆都指向错误答案，是最难的情形。
- 问题问的是"现在"的值，两个选项是这两个取值，正确答案是新值。
- 会话构建：旧值放在第一个种子会话，更新放在后面的种子会话。
- 更新句写成 "we changed X from A to B" 或 "X is now B"，**不加任何惊讶语气**。

### 2.4 无先验对照（neutral）
- 两个版本记为 A 和 B，选项是两个同样任意的取值，例如"备用钥匙放在蓝色还是绿色的抽屉里"。
- 在分析里，A 版本当作"C"、B 版本当作"I"处理，只是为了沿用代码。

## 3. 门槛（阈值在测量运行之前固定）
| 门槛 | 方法 | 入选规则 |
|---|---|---|
| **G0 格式** | 构建脚本自检：字段齐全、只换关键词、提示词黑名单、ID 和话题唯一 | 全部通过，不通过就修改条目，不计入淘汰 |
| **V1 先验强度** | 20 次强制二选一（两种选项顺序各 10 次，T = 1），用 4 个模型家族：Qwen3-235B（主读题和压缩模型）、Llama-3.3-70B、gpt-oss-120b、DeepSeek-V3.2。prompt 与原来的 `validate.py` 相同 | rule、procedure、preference、update：**Qwen3-235B 上 P(C) ≥ 0.8**，与原来相同；update 的 P(C) 指"不给信息时选符合常识的取值"的概率。neutral：Qwen3-235B 上 0.3 ≤ P(A) ≤ 0.7。其他 3 个模型的结果都单独报告；第 4 步用到的第二个模型家族也要满足 ≥ 0.8，那个子集在第 4 步开始前定义 |
| **V2 理解检验** | 刚听完就问。C、I 两个版本 × 两种选项顺序，共 4 次，T = 0；update 类先听旧值再听更新。用 Qwen3-235B、Llama-3.3-70B、gpt-oss-120b 三个模型 | Qwen3-235B 上 4/4 答对，**并且**其余两个模型各自至少 3/4 答对 |
| **干扰会话泄漏检查** | 两层：先用每个条目的话题词和两个答案词自动筛一轮，再对被标记的"干扰会话 × 条目"组合用 LLM（gpt-oss-120b）判断是否提到或暗示了该条目 | 被判泄漏的干扰会话从池子里去掉 |
| **V3 正对照** | 抽 120 条做分层子集，复用原来的 Bartlett 链（叙事版和清单版，6 代，T = 1）和两个评判模型 | 不作为单条的入选门槛，而是验证整批材料：预测改写方向为 I → C 的比例高于 C → I（与原 V3 一致） |

**最终入选**：通过 G0、V1、V2 的条目全部入选。超过 500 条也全部保留，绝不按下游效果挑选；不足 500 条就如实报告。

## 4. 人工抽查（第 3.3 项，由 PI 团队完成）
- 按类型 × V1 强度分层，抽 100 条，生成审阅表 `human_review_sheet.csv`。
- 每条要评的项：读起来是否自然；C/I 两个版本是否只差关键内容；I 版本作为本地约定是否说得通；有没有提示词或暗示；问题和选项是否清楚。
- 在真人完成之前，不报告任何人工结果。
