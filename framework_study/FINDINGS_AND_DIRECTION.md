## 0. 一句话
**记忆删除内容时并不区分常识与反常识，但被删掉之后，agent 会用先验把空缺补回来。** 所以向先验回归发生在"读记忆"的时候，而不是"写记忆"的时候。直接后果是：用"合理的"事实来考记忆系统，分数会被先验大幅抬高。

## 1. 证据摘要

**实验设置**
- 12 个记忆系统（11 个主流系统加上 Nemori，见 §9），外加完整历史作为上限。另外用本地 Qwen3-8B 复现了其中 7 个系统（见 §10）。
- 每个系统 43 个模拟用户，44 对反常识 minimal pair（C = 符合常识，I = 违背常识）。
- 写入后再经历 12 个无关会话；压缩模型统一用 Qwen3-235B。

**第 12 个会话之后的结果**

**机制分解**（把第 2 个会话及之后的检查点合并统计）
- 条目还在记忆里：C 和 I 的答对率都约为 1.00。
- 条目被删掉：C 仍有 0.91–0.98 答对，因为先验能猜中；I 只有 0.02–0.12，agent 直接退回常识答案。
- 反常识知识的损失中，**98–100% 来自删除**，而不是来自改写。
- 记忆文本向常识方向被改写（"翻转"）的比例 ≤1%。删除对 C、I 一视同仁，保留率之差的 CI 都包含 0；唯一的例外是 Gemini CLI，它对反常识的描述性条目反而保留得**更好**。以上都是强压缩模型下的结果；换成弱模型后，中性重写出现了 +9.1 个百分点的方向性删除，见 §10。

## 2. 被证实和没被证实的部分

**被证实：问题存在，而且很严重。**
- 用主流记忆系统搭建的 agent，对反常识知识的答对率从约 95% 掉到 1–72%（取决于系统）；对常识内容始终保持在 95% 以上。
- "记忆最需要保住的内容最容易丢"、"in-context 持续学习存在天花板"这两个论点在行为层面成立。
- 结果在 12 个系统上方向一致，CI 远离 0；换成弱压缩模型后同样成立（§10）。

**没被证实：原先的机制。**
- "压缩本身就是 iterated learning，记忆文本会被拉向先验"这一说法不成立：删除不看内容，改写几乎为零。
- 真实机制分两步：**压缩不加区分地删除，然后读取时由先验补全。** 这更接近 Bartlett 的"重建式回忆"，而不是"传话链"。
- 补充（§10）：换成弱压缩模型 Qwen3-8B 后，改写仍然几乎为零（≤1.2%）。但在唯一没有删光的中性重写里，出现了按先验方向的删除：+9.1 个百分点，95% CI [+0.7, +18.4]。也就是说，iterated learning 预测的"选择通道"在弱模型上有苗头，而"改写通道"在强、弱两种模型上都不成立。另外，V3 正对照中"从大意重建"会产生 4–5% 的单向规整。

## 3. 必须正视的风险
审稿人可能会说："删掉信息之后模型去猜默认值，这是显然的。"所以论文不能只停留在"问题存在"，而要把下面三点作为贡献。

第二个预期的质疑是："固定同一个底座模型时，先验对所有框架都一样，对比已经抵消了先验。"这个质疑在 §12 中用得分分解和放弃作答率的数据回应：这一说法只在两个条件下成立，而实际中两个条件都不满足。

## 4. 三个候选贡献

### 贡献 1："删除不看常识与否"本身是一个有信息量的负结果
- 理论（iterated learning、先验驱动的选择）预测删除应当偏向反常识内容。我们第一次在真实系统上把先验契合度作为受控变量来检验这个预测，结果是没有偏向，并给出了足够窄的置信区间。
- 定位：一个明确的、可证伪的预测得到了否定答案，可以作为论文的一部分，但不宜作为主线。

### 贡献 2（主线候选）：现有 agent memory benchmark 把"猜对"算成了"记住"

**论点**
- 常规记忆基准里的事实和偏好，大多是"合理的"或"可以猜到的"。即使记忆系统把它们丢了，底座模型也能凭先验答对。
- 因此，这些基准测的是"记忆 + 先验"的混合能力，系统的真实记忆能力被高估，系统之间的差距也被压平。
- **精确的表述（见 §12.4）**：绝对分数和差距大小必然受先验影响；排名是否可靠，取决于各系统放弃作答倾向和保留选择是否一致（LoCoMo 稳定，MemoryAgentBench-AR 改变）；现有基准测不到反先验知识。不能宣称"现有排名都不可信"。

**我们现有的直接证据**
- Aider 实际保留率为 0%，常识题得分却是 97%；Codex 保留 7%，常识题 96%；Anthropic API 保留 9%，常识题 98%。
- 只看常识题，12 个系统全部挤在 95–100%，**几乎无法区分**。只看反常识题，分数从 1% 到 95% 依次拉开，排名与真实保留率基本一致。
- 混合题（一半常识、一半反常识）的分数也会把真实保留率高估 0.07–0.49。

**我们的 benchmark 设计**
- **成对的 minimal pair**：同一个槽位分别给出符合常识（C）和违背常识（I）的版本，其余内容完全一样。
- **核心指标**：
  - **反常识准确率**（I-accuracy）：唯一不能靠先验猜中的部分；
  - **信念差距**（C 准确率减 I 准确率）；
  - **扣除猜测之后的准确率**：(acc − g) / (1 − g)，其中 g 是不给记忆时的猜中率。
- **双重测量**：既看记忆文本的状态（保留、删除、翻转），也看 agent 的回答，从而区分"没存下来"和"存了但没用上"。
- **质量门槛**（V1–V3），每个条目都要逐条通过：
  - V1 先验强度：不给信息时，模型选常识版本的概率 ≥ 0.8；
  - V2 理解检验：刚听完就问，必须答对，排除"模型会主动纠正"的条目，例如 S02、S08；
  - V3 正对照：确认这套材料在从大意重建时能诱发单向规整。
- **条目的植入方式**：在完成别的任务时顺带提到，而不是郑重列成清单；不加 "actually" 之类的提示词；带有"规范性"标签。

**查新（已完成，详见 §7）**
- **已知的相关做法**：
  - Zhang et al.（2605.12978）在 PropWorld 设计笔记里发现，用有意义的数值时，无记忆 agent 零样本可以答对 91%，于是改用无意义的 nonce；
  - MemoryAgentBench 的 FactConsolidation 用反事实更新值（MQuAKE），以避免参数知识泄漏；
  - knowledge-conflict 领域也有类似做法（ClashEval、ConflictQA、CounterFact）。
- **我们的区别**：
  - 他们是**消除**先验（nonce、反事实），我们是**量化**先验如何抬高分数，并且在保持内容真实、有意义的前提下把"记住"和"猜中"分开；
  - 用 nonce 测出来的记忆能力在现实中偏乐观或偏悲观都有可能，而反常识的真实知识（例如用户的特殊偏好、和常识相反的本地事实）恰恰是部署中最需要记住的内容。
- **查新结论（§7）**："先验会抬高分数"这个原则已有人提出（Ground Truth First、MemGym、100-LongBench）。没有人做过的是：系统审计旧基准、给现有系统重新打分、同一槽位的成对设计。最大的撞车风险是 PersonaMem-v2。

**要把这一点立住所需的实验（进度，2026-10-10）**
1. ✅ **审计现有基准**（§8、§8.1）：覆盖 4 个基准，用了 2 个答题模型；能被先验答对的比例从 7% 到 63%。LoCoMo 和 PrefEval 是 CC BY-NC，只做测量，不再分发。
2. ✅ **重新打分**（§11）：MemoryAgentBench-AR 上 9/11 个系统在抗先验题上 ≤4%，排名 Spearman 0.664（用平均秩处理并列后为 0.779，没有确认的排名反转，见 §13.3）；LoCoMo 第 1–4 类排名稳定，而第 5 类反过来奖励遗忘。
3. ⏳ 未做。**扩展我们的 benchmark**：从 44 对扩到数百对；覆盖事实、流程、偏好、知识更新等类型；建立自动生成加 V1–V3 质量门槛的流水线；换多个底座模型重测先验，因为先验因模型而异。
4. ⏳ 未做。**人工校验**：抽取 150 条，人工核对评判模型的标注，已有的样本可以复用。

### 贡献 3：决定损失的是改写的"范围"，而不是"有没有改写"
- 只改写局部相关条目的 Mem0 1.0.11 最稳：保留率 0.93，信念差距 +0.04。
- 只追加的 Mem0 2.2.1 只在写入那一刻（抽取阶段）丢东西，之后完全平稳。
- 每次把整份记忆重写一遍的系统，几个会话就丢掉大部分内容：LangChain、Codex、OpenHands、Anthropic API、Aider，以及 LlamaIndex 的 condense 步骤。
- Nemori（只追加加检索，§9）同样 100% 保留，进一步支持这一点。
- 弱压缩模型（§10）让整体重写的系统几乎删光（保留 0–4%）。
- 这对记忆系统设计有直接意义：局部更新或只追加，加上原始记录作为锚点，优于整体重写；代价是记忆体积不断增长。
- 还需要补的实验：
  - 改变压缩触发频率和上限。LlamaIndex 默认的 max_facts=50 已经在基准重新打分中使用（§11），框架实验里用的仍是 12；
  - 让无关会话带一些语义相近的干扰，测试局部更新何时会误伤；
  - 把缓解方式（锚点、局部更新）做成受控对照。

## 5. 论文框架草案（待定）
- **暂定题目**：*Your Memory Benchmark Is Measuring the Prior* 或 *Remembering vs. Guessing: Counter-Schema Probes Reveal What Agent Memory Actually Keeps*
- **结构**：
  1. 现象：记忆向先验退化，但发生在信念层面；
  2. 诊断：现有 benchmark 无法看到这一点（贡献 2）；
  3. 方法：minimal pair benchmark 加 V1–V3 质量门槛；
  4. 实证：12 个系统的框架实验，加 4 个现有基准的审计（2 个答题模型），加 12 个系统的重新打分，揭示改写范围决定损失（贡献 3）；
  5. 理论："不加区分地删除、由先验补全"的机制得到支持。iterated learning 的预测在强压缩模型上被否定，在弱模型上，"选择通道"有苗头（贡献 1、§10）。
- **与 ACL 2027 主题的关系**：知识坍缩与同质化。记忆的损失让 agent 回到"平均"的先验，个体差异（用户的特殊偏好、本地的特殊事实）首先消失。

## 7. 查新结果（2026-10-06，3 个并行检索方向，所列论文均已打开原文核实）

**结论**："先验会抬高记忆评测分数"这个**原则本身不新**，不能作为贡献宣称。以下三点目前**没有人做过**，可以作为贡献：
- (a) 对**已有的主流 memory benchmark** 做系统的、逐题的、跨基准的"可被先验答对比例"审计，使用多个模型，并区分"强制猜测"和"允许不答"两种协议；
- (b) 用"抗先验子集"或"扣除猜测"的指标**重新给现有记忆系统打分**，看分数虚高和排名变化；
- (c) 在**同一个槽位**上做"符合常识与违背常识"的 minimal pair，覆盖事实、流程和偏好等多种类型，配上"记忆贡献"指标；并给出因果链："写入时删除不区分先验"导致"读取时向先验回归"。

**最接近的工作与撞车风险**

| 工作 | 内容 | 与我们的关系 |
|---|---|---|
| **PersonaMem-v2**（2512.06688） | 偏好分为刻板、中性、反刻板三类，准确率依次为 48.9%、41.6%、33.0%，并明确归因于 "population priors" | **最大撞车风险**，针对 (c)。区别：只涉及偏好；不是同一槽位的成对设计；没有无记忆基线和扣除猜测的指标 |
| Know It, Act on It（2607.29433） | 复现上面的刻板与反刻板差距；无记忆基线低于 3% | 同上 |
| Ground Truth First（2607.21962，独立作者） | 明确提出 "a memory score partly measures the model's priors"；在自己的虚构数据上，无记忆对照得 15–17% | 原则相同；没有审计 LoCoMo、LongMemEval，也没有重新打分 |
| MemGym（2605.20833） | 不做虚构化时，前沿模型凭预训练知识就能得 0.70–0.85；虚构化后接近 0 | 只针对它自己的基准 |
| LongMemEval-V2（2605.12493）、RECON（2607.16716）、EverMemBench、DolphinBench | 构建基准时就把能被先验答对的题过滤掉 | 只是"过滤"，没有回头审计旧基准 |
| 100-LongBench（2505.19293） | 长上下文 QA：无上下文基线显示分数虚高，修正后排名会变 | (a)(b) 在**长上下文**领域已有，在记忆领域还没有 |
| LastingBench、SeedRG、CConS、NoCha、ClashEval、FaithEval | 用反事实或违背常识的上下文、minimal pair 做忠实度评测 | 设计相同但领域不同，需要引用 |
| MirageBench（2608.04570） | 记忆中的刻板化"补全"（虚构用户属性），刻板 persona 高出 7.8 个百分点 | 对应我们"读取时由先验补全"的一个特例 |
| **Nemori**（2508.03341） | "Predict-Calibrate"：只存储模型预测不到的内容，是一种**考虑先验的写入策略** | **必须引用并作为对照**，否则"记忆删除不区分先验"这个说法要收窄 |
| Emergence AI 博客 | LongMemEval 上 "Best Guess" 基线得 18.8%，"I don't know" 基线得 5.8% | 非正式，只覆盖一个基准；和我们的结果一致 |
| MemDelta（2606.29914） | LongMemEval-S 上无记忆基线 2.2%，允许不答 | 说明协议不同，结论会差很多 |

**定位建议**：在记忆领域，现在的做法是在**新建**基准时把能被先验答对的题过滤掉，而在 RAG 和知识冲突领域，反事实上下文早已是标准设计。我们要做的是这些工作都没做的三件事：回头**量化**旧基准、**重新打分**、用**成对设计**估计每个条目对先验的依赖程度，并把写入和读取两端的因果机制连起来。

**排除 bug（三项都排除了）**

- 文档完整读完了：Aider、LangChain、neutral_roll、Gemini CLI 的最终记忆都提到了最后一份文档（Document 1199–1204，忽必烈攻宋）。它们与最后一块的专有名词重合率为 0.56–0.70，与第 1 块只有 0.11–0.21。
- 读题和判分正常：标准答案出现在上下文里时，Mem0 答对 82%，raw_rag 答对 70%。

**压缩型系统确实丢掉了内容**
- 在抗先验题上，它们返回的上下文中只有 0–2% 含有标准答案（Mem0 为 83%，raw_rag 为 59%）。
- 在后三分之一的题上同样是 0 分。原因是 100 道题里只有 6 道的证据在最后 5 块，而摘要基本只留住了最后一两块。

**两个典型的失败方式**
- OpenHands 的压缩器只记"任务状态"，记忆内容是"用户正在提供第 1199–1204 份文档，已全部存储"。它一点内容都没留，还虚构了"1204 份文档都已保留"。
- Anthropic 的压缩 prompt 把记忆逐渐改写成抽象的"跨学科综合框架"，文档编号停留在 309–826，与最后一块的重合率只有 0.05。

**必须写进论文的限定**
- 我们让每个系统每读一段（1,000 词）就压缩一次，读完 QA1 共压缩约 155 次；LoCoMo 每段对话压缩约 19–32 次。真实产品只在上下文接近上限时才压缩，按 Qwen3-235B 约 25 万 token 的上下文窗口计，读完这份文档只需压缩一两次。
- 因此这里的低保留率反映的是"高频压缩压力下这类机制留得住多少"，**不能写成产品在实际使用中的表现**。
- 另外，Mem0 和 LlamaIndex 的默认 prompt 是为提取个人信息设计的，LlamaIndex 默认最多存 50 条事实，拿来记百科文档本来就不对口。这同样是设置条件，要写明。
- 论文的核心论点（基准把猜中算成记住，PCME 能把两者分开）并不依赖哪些系统记忆为空：记忆接近空的系统恰好是展示"虚高"的例子。但凡涉及具体系统的结论，都要加上上面的限定。
- 建议做稳健性检查：改成"上下文超过阈值才压缩"，看结论是否保持。是否执行，等 PI 决定。

## 12. 固定底座模型能不能抵消先验？（预先回应审稿人质疑，2026-10-10）

**问题**（PI 提出）：对比不同记忆框架时，大家通常固定同一个底座模型，于是所有框架的先验都一样。这样一来，现有基准的框架对比是不是已经把先验"过滤掉"了？如果是，我们的论点还站得住吗？

脚本：`benchmark_audit/fixed_model_check.py`；结果：`benchmark_audit/results/fixed_model_check.txt`。

### 12.1 得分分解
对系统 s 和题目 i：R_si 表示条目被保留并且能用上的概率；g_si 表示没保留时凭先验答对的概率。则

> acc_s = mean_i [ R_si + (1 − R_si) · g_si ]

如果满足下面两个条件：
- **(A)** 保留哪些题与题目好不好猜无关；
- **(B)** 不管用哪个系统，凭先验答对的概率都一样（g_si = g_i）；

那么 acc_s = ḡ + R_s·(1 − ḡ)。这时**先验只是一个常数偏移加上一个压缩系数 (1 − ḡ)，排名不变**。PI 的直觉在这两个条件下成立。

### 12.2 实测检验（固定答题模型 Qwen3-235B）

| | MemoryAgentBench RULER-QA1 | LoCoMo 第 1–4 类 |
|---|---|---|
| 可被先验答对的题上，各系统的放弃作答率 | **0%（Mem0）到 59%（Codex）** | **5%（Raw RAG）到 64%（Aider）** |
| 隐含猜中率 ĝ = (acc_可答 − acc_抗) / (1 − acc_抗)，跨系统范围 | 0.31–0.74（sd 0.137） | 0.08–0.54（sd 0.134） |
| Spearman（放弃作答率，可答题准确率） | **−0.83** | **−0.95** |
| 排名 Spearman（全部题目对抗先验子集） | **0.664**（用平均秩为 0.779，见 §13.3） | **0.979**（排名稳定） |

**典型例子（MemoryAgentBench）**：Codex 和 Anthropic API 在抗先验题上都是 **0.000**，真实记忆贡献相同；但原始分分别是 0.150 和 0.240。差别完全来自可答题上的放弃作答率：59% 对 33%。9 个抗先验准确率 ≤5% 的系统，原始分在 0.15–0.35 之间，与放弃作答率的 Spearman 为 −0.73。

### 12.3 解读：固定模型并不能抵消先验，原因有四
1. **条件 B 在两个基准上都不成立。** 各系统给出的上下文不同，会改变模型是去猜还是回答"不知道"，所以先验带来的加分**因系统而异**。
   - MemoryAgentBench 上，记忆接近零的系统之间的排名，比的其实是"敢不敢猜"，而不是记忆。
   - LoCoMo 上同样不成立，但方向恰好不改变排名：记忆越差的系统越常放弃作答，先验加分更多流向本来就好的系统，所以排名不变、差距被拉大。**排名稳定是一个碰巧的结果，不是固定模型带来的保证。**
2. **条件 A 也可能不成立。** 弱压缩模型下的中性重写出现了按先验方向的删除（+9.1 个百分点，§10）；强模型下没有观测到。
3. **即使排名不变，数值也被扭曲。**
   - 绝对分数被抬高，系统之间的差距被压缩，例如 LoCoMo 算上第 5 类后，系统间极差从 0.483 降到 0.354；
   - "X 比 Y 高多少""接近完整上下文"这类说法都会受影响；
   - 跨底座模型的对比，先验本身就不同，固定模型这一招根本用不上；
   - LoCoMo 第 5 类（无法回答的题）和记忆能力负相关（§11.2）。
4. **固定模型测不出"丢的是哪类知识"。** 反常识知识在信念层面丢得最多（§1），而由任意或常识事实组成的基准结构上就看不到这一点，跟固定不固定模型无关。只有 C/I 成对设计能把它测出来。

### 12.4 对论文表述的影响

**不能说**："现有基准上的框架排名都不可信"或"都被先验混淆"。审稿人会用 12.1 的论点反驳。

**应该说**：
- (a) **绝对分数和差距大小必然受先验影响**，需要报告抗先验子集的分数或扣除猜测后的分数。
- (b) **排名是否可靠，取决于各系统放弃作答的倾向和保留哪些题目是否一致。** LoCoMo 碰巧不改变排名；MemoryAgentBench-AR 的排名明显改变，并给出机制：放弃作答率。
- (c) **现有基准测不到"反先验知识"这一块**，而 C/I 成对设计可以测。

**对评测规范的建议**（可以写成贡献的一部分）：
- 同时报告全部题目、抗先验子集和可被先验答对子集的准确率；
- 报告放弃作答率；
- 同时报告"强制作答"和"允许不答"两种协议下的结果；
- 用 C/I 成对条目测反先验知识的保持情况。

### 12.5 局限
- ĝ 的估计假设抗先验题上 g≈0，并且两个子集的保留率相同；可被先验答对的题多偏向通用知识，保留率可能本来就不同，所以 ĝ 混合了"保留率的差异"和"敢不敢猜"两种因素。放弃作答率是更直接的证据。
- 放弃作答用正则识别，只是近似。
- 只用了一个答题模型。

### 13.2 这一步学到的东西（这些都会写进论文的方法部分）

1. **只靠 prompt 指令做不到强制作答。**
   - 在 π_F 评测 prompt 下，记忆为空时的拒答率：LongMemEval 75%，LoCoMo 36%，MemoryAgentBench 2%。
   - 上下文里只有无关内容（BM25−证据）时：LoCoMo 38%，MemoryAgentBench 28%（其中 QA1 为 42%）。
   - 闭卷 prompt 在 LoCoMo 和 MemoryAgentBench 上的拒答率都不到 1%。

2. **g 必须用评测时完全相同的 prompt 和题面来估计，唯一的区别是去掉记忆内容。**
   - 用别的形式的闭卷 prompt，会高估计分时真正相关的猜中率：LoCoMo 0.149 对 0.102，LongMemEval 0.133 对 0.071。
   - prompt 一致之后，下限是准确的：三个基准上 Empty 的 MA 都在 ±0.013 以内。
   - T=1 抽取和 T=0 运行的结果几乎相同（LoCoMo 0.102 对 0.105），所以解码方式的差别影响不大。

3. **随上下文变化的拒答，是 PCS 面临的主要威胁（假设 A2）。**
   - 以下是探索性分析（MemoryAgentBench 按子集拆开）：
     - QA1：D = −0.080 [−0.163, 0.000]。有无关文档块时，拒答率从 0.10 升到 0.42；
     - QA2：D = +0.067 [+0.010, +0.127]。同一文档里的相关段落帮助了猜测，这部分本身就是记忆的贡献。
   - 合并之后的"等价"掩盖了这种异质性。
   - 结论：CPR 继续作为主指标，PCS 作为辅助指标，必须同时报告每个系统的拒答诊断；第 2 步加入"追问"作为第三种协议（π_F+R）。

4. **抗先验分层有效。**
   - 泄漏率的 95% 上界在三个基准上都 ≤ 0.011。
   - 给出证据后，抗先验题可以答对：CPR_Oracle 在 LoCoMo 上为 0.76，在 MemoryAgentBench 上为 0.72。
   - 所以真实系统在抗先验题上得分接近 0，原因是记忆，而不是题目答不出来。

5. **即使给了证据，抗先验题也略难一些。**
   - 按"读不懂时退回去猜"的两状态模型拆分：
     - MemoryAgentBench：p_R = 0.72，p_A = 0.83–0.89，难度部分为 0.12–0.17；
     - LoCoMo：难度部分为 0.01–0.05，具体取决于 g 的定义。
   - 按规则，第 2 步要同时报告 oracle 归一化的 CPR_s / CPR_Oracle，以及 LoCoMo 按类别的结果。

6. **与真实保持率对照（框架实验）。**
   - PCS 的平均绝对误差是 0.018，原始准确率是 0.303。
   - 但两者的相关系数相同（都是 0.998）。原因是在 C/I 平衡设计里，原始准确率本来就是保持率的线性变换。
   - 所以原始准确率的问题在**尺度**：它的地板被抬到 ḡ，系统之间的差距被压缩。它的**排序**本身没有问题。排序只有在系统之间猜中率不同时才会被打乱，例如放弃作答率不同（§12）。
   - 预先登记的相关系数标准选得不好，如实记为"未得到支持"。

7. **已知保持率下的示意（P5，在真实回答上模拟）。**
   - 在 LoCoMo 上保持一半条目时，无论删掉的是可猜的题还是不可猜的题，原始准确率几乎一样（0.47 对 0.46）。
   - 但真实的反先验保持率差别很大（0.70 对 0.29），CPR 能跟上这个差别（0.55 对 0.29）。
   - 随机删除时，ORS 能恢复已知的 r。在 (a) 下：
     - LoCoMo 依次为 0.08、0.31、0.54、0.77、1.00；
     - MemoryAgentBench 依次为 −0.01、0.24、0.50、0.75、1.00。

8. **"可被先验答对的比例"取决于抽取次数，之前写的"上界"是错的。**
   - 随着抽取增多：
     - LoCoMo：16%（Qwen 单次 T=0）→ 24%（两个模型取并集，T=0）→ 29%（Qwen 6 次加 Llama）；
     - LongMemEval：15% → 25% → 31%；
     - MemoryAgentBench QA1：38% → 49% → 54%。
   - "至少猜中过一次"只能给出下界，并且会随抽取次数 K 增大。
   - 回答"期望上有多少题能靠猜答对"，应该报告闭卷强制作答下的平均 ĝ：LoCoMo 0.149，LongMemEval 0.133，MemoryAgentBench QA1 0.353、QA2 0.430、EventQA 0.450、FactConsolidation-SH 0.192、FactConsolidation-MH 0.012。

9. **在 LoCoMo 上，12 个系统的 CPR 排名不随先验估计方式改变**（τ_b ≥ 0.93）。在 MemoryAgentBench-QA1 上，τ_b 为 0.67–0.89，这里抗先验题只有 46–62 道。

### 14.3 结论（实质部分）
1. **放弃作答率左右着原始分数的变化，这一点在两个基准上都成立**（H1、R3）。在 MemoryAgentBench 上，强制作答让记忆接近零的系统提分最多 +0.20（Aider 从 0.15 升到 0.35），而它们的记忆完全没变。
2. **只统一作答协议，并不能恢复按记忆的排名**（H2 不成立，这是登记过的预测没有成立）。探索性的解释：强制作答之后，记忆接近零的系统在 𝓐 层上都向猜中率收敛（0.39 → 0.56，g' = 0.605），彼此几乎并列，它们之间的排名就只剩噪声。可见统一协议只消除了放弃作答带来的差异，要把记忆和猜测分开，还得靠先验分层（CPR / PCS）。这对方法是支持，但必须写明这是事后解释。
3. **CPR 在 LoCoMo 上对协议不敏感**（最大差异 0.018）。**在 MemoryAgentBench 上不满足**，有两个原因：
   - 抗先验题只有 46 道，±0.03 的等价区间在这个样本量下几乎不可能达到；
   - 原生协议在证据就在上下文里时也可能压低正确回答，例如 LlamaIndex 在强制作答下 CPR 提高了 +0.087。
   - **对方法的修改建议：CPR 统一在 π_F（或 π_F+R）下计算**，与 PCS 保持一致。这要在 METHOD v1.3 里登记，属于第 2 步结果带来的修改。
4. **不可回答题的计分方式奖励遗忘**（H7，效应很强）。区分度 J 能纠正这一点：记忆接近零的系统 J 只有 0.07–0.15，raw_rag 为 0.32。
5. **时间类问题**（LoCoMo 第 2 类）：在抗先验题上，除 raw_rag（0.46）和 mem0（0.15）以外，所有系统都 ≤ 0.05。摘要会丢掉日期。
6. **没有任何排名反转在统计上得到确认**。论文的论点应该落在"虚高、尺度压缩、放弃作答的混淆"上，不能写成"排名被颠倒"。
7. **追问只能部分解决不遵从**（H5 在 MemoryAgentBench 上不成立）：是否追问由正则决定，漏掉了 LLM 判出的一部分拒答，而且有些系统追问后仍然拒答。

### 14.4 对论文论点的影响
- **立得住的论点**：
  - 基准分数被先验抬高；
  - 系统之间的原始分差异被放弃作答混淆（H1、R3）；
  - 不可回答题的计分奖励遗忘（H7）；
  - CPR 在 LoCoMo 上稳定；
  - 高频压缩下记忆接近空，而阈值触发下记忆明显变好（R1）。
- **要弱化或加限定的论点**：
  - 不再说"排名被颠倒"；
  - "统一协议能恢复记忆排名"不成立（H2）；
  - 阈值触发下的虚高在 QA2 复现之前要加限定（R2）。

**花费**：第 2 步目前约 $76（$83.05 → $159.36），QA2 剩余部分预计还需不到 $5。


### 14.5 QA2 独立复现与稳健性检查的 QA2 部分（2026-10-11 补，METHOD §10.5、§10.6）

**QA2 复现**：100 题，其中抗先验题 40 道，11 个系统。复现成立的标准是方向相同，并且 95% 置信区间不含 0。

| H2 | Δτ = −0.210 [−0.348, +0.129] | 没有复现，与 QA1 一样不成立 |
| H3 | 6/11 个系统达标（最大差异 0.025） | 预测是至少 9/11，不成立；主要原因是只有 40 道抗先验题，样本太少 |
| H4 | 标准差之比 0.46 [0.31, 0.86] | **成立** |

关于 H4：记忆接近零的系统，在 𝓐 层上的平均准确率从 0.54（原生协议）升到 0.68（强制作答），猜中率 g' 为 0.61。QA1 上这一条处在边界，没有通过。

## 16. 第 4 步：换一个模型家族复现框架实验（2026-10-11）

**相关文件**
- 设计与预先登记：`framework_study/STEP4_DESIGN.md` v1.0，commit 9586d86。它在冒烟测试之后、正式运行之前提交。
- 分析：`src/analyse_step4.py`，结果在 `results/step4_analysis.{txt,json}`。

**设计**
- Qwen3-235B 和 Llama-3.3-70B 各自同时担任压缩模型和读题模型。
- 条目子集 S4 共 432 对：两个模型的先验都够强；无先验对照要求两个模型都在 0.3–0.7 之间。
- 9 个系统，192 个模拟用户，每个条目出现 3–4 次，C/I 版本平衡分配。
- 在最后一个检查点（第 12 个干扰会话之后），两个家族各有 13,824 次条目探测。

**运行中的问题**
- Bedrock 对 Llama 限流（HTTP 429），导致 Mem0 和 mem0_v1 在 Llama 下 192 个用户全部失败，其他系统失败 4–21 个用户。
- 失败按整个用户随机发生，与条目版本无关。用 `run_step4_repair.sh` 以较低并发补跑，18 个运行全部补齐到 192 个用户，然后重新跑了探针。
- 花费约 $119。

### 16.1 预先登记的判定
| 编号 | 预测 | Qwen | Llama | 判定 |
|---|---|---|---|---|
| **P4.1**（主检验） | 整份重写类系统的 ΔR，95% 置信区间在 ±0.05 内 | codex −0.018 [−0.043, +0.005]、aider 0.000、anthropic −0.017 [−0.040, +0.004] 达标；neutral_roll −0.011 [−0.061, +0.040] 下界略超 | — | **3/4 成立**（所有点估计都接近 0） |
| P4.2 | 所有系统 ΔF ≤ 0.02 | 9/9 | 9/9（最大 0.004） | **成立** |
| **P4.3**（主检验） | 删除率 ≥ 50% 的系统 ΔK > 0；删除率与 ΔK 正相关 | 4/4 个系统；ρ = 1.000 | 4/4 个系统；ρ = 0.967 | **两个家族都成立** |
| **P4.4**（主检验） | 两个家族下各系统保持率的 Spearman ≥ 0.7 | ρ = 0.950 | | **成立** |
| P4.5 | 无先验对照 \|ΔK\| ≤ 0.10 | −0.116 [−0.315, +0.104] | +0.435 [+0.167, +0.676] | **不成立**（原因见 16.2 第 4 点） |
| P4.6 | 更新违背先验时更容易退回旧值 | +0.434 [+0.409, +0.460] | +0.467 [+0.440, +0.493] | **成立，效应很大** |
| P4.7 | MAE(PCS, R) < MAE(原始准确率, R) | 0.013 对 0.205 | 0.011 对 0.234 | **成立** |

**关于 Holm 校正**：预先登记写了对主检验做 Holm 校正，但 P4.1、P4.3、P4.4 的判定标准都是置信区间准则，本身不产生 p 值，所以 Holm 校正没有被具体落实。这一点记为偏离。三项主检验的效应都极大（ΔK 的置信区间远离 0；n = 9 时 ρ = 0.95），是否校正不影响结论。

### 16.2 结论
1. **原有结论在扩展后的数据集上、换成另一个模型家族后都复现了**：
   - 删除基本不区分 C 和 I（ΔR ≈ 0）；
   - 改写几乎从不翻成符合常识的版本（ΔF ≤ 0.004）；
   - 记忆丢得越多，信念差距 ΔK 越大（ρ ≈ 1）；
   - Aider、Codex、Anthropic 在两个家族下 ΔK 都在 0.87–0.96 之间。
2. **系统之间保持率的排名跨家族稳定**（ρ = 0.95），但具体数值会随压缩模型变化：
   - neutral_roll 在 Llama 下删掉了 94%，在 Qwen 下只删 30%；
   - Mem0 在 Llama 下几乎什么都没丢（删除率 0.00），在 Qwen 下删除率为 0.20；
   - LlamaIndex 在 Llama 下保留得比 Qwen 下多（删除率 0.44 对 0.77）。
   - 结论：压缩的激进程度取决于底座模型。
3. **知识更新类是新发现**：当新值违背先验时，智能体退回旧的、符合常识的值的比例高出 43–47 个百分点，两个家族一致。旧记忆加上先验，会联合压倒更新。
4. **无先验对照没有通过**（P4.5）。探索性分析：
   - 条目被删掉后，T=0 下模型对每个无先验条目的选择几乎是固定的，多数条目要么总选 A、要么总选 B；这个选择与 T=1 下偏好的选项吻合的比例为 65%（Qwen）和 78%（Llama）。
   - A/B 标签是编写时为每个条目固定的，而 S4 里只有 10 个这类条目。Llama 下 8/10 个条目偏 A，所以 ΔK 偏正。
   - **教训**：
     - 无先验对照要用读题时同样的解码方式（T=0）来验证；
     - A/B 标签应当按用户随机分配，这样 ΔK 的期望才严格为 0；
     - 条目数要更多。
   - 这和第 1 步的教训是同一个：先验必须在评测时的解码方式下测。
5. **探索性观察：事实提取类记忆有小幅偏向先验的删除**。LlamaIndex 在 Llama 下 ΔR = +0.072 [+0.021, +0.124]，在 Qwen 下 +0.042 [−0.002, +0.087]。其他系统在两个家族下的 ΔR 都接近 0。
   - Llama-70B 作为较弱的压缩模型，并没有像 Qwen3-8B 那样普遍出现先验导向删除：两个家族的 ΔR 之差在 −0.022 到 +0.030 之间。
   - 登记时的探索性预测"Llama 下 ΔR 更偏正"没有得到支持。
6. **PCS 与真实保持率高度一致**（MAE ≈ 0.01），原始准确率则偏离 0.2 以上。这是方法论文的直接证据。

**prompt 存档**：已补充第 4 步的 Llama 压缩重放和信念探针样例。现在共 46 个模板、124 个真实请求样例，全部核对通过。
