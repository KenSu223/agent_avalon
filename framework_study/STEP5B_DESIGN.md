# 收尾项 5b：弱压缩模型的先验导向删除，不触底版本（设计与预先登记 v1.0）

写于 2026-10-11，对应 PLAN 第 5 项的第二小项。PI 已于同日决定：改用 Bedrock 上的小模型，因为本地 GPU 被其他项目占用。本文件在正式运行之前提交。

## 1. 问题
- FINDINGS §10：本地 Qwen3-8B 作为压缩模型时，neutral_roll 出现了 +9.1 个百分点 [+0.7, +18.4] 的先验导向删除，即违背常识的条目被删得更多。但那组运行中大部分系统都把条目删到接近 0，处在"触底"状态，难以判断。
- 本项要回答：**在保持率没有触底或封顶的区间里，弱压缩模型是否会优先删掉违背常识的条目。**

## 2. 设计
- **弱压缩模型**：Llama-3.1-8B-Instruct（Bedrock）。
  - 选它的理由：规模与 Qwen3-8B 最接近；不承担评判。
  - **注意**：它与 Qwen3-8B 属于不同的模型家族，所以本项只能作为概念上的复现，结果不能和 §10 逐条比较。
- **条目**：用户历史与第 4 步完全相同，包含全部 S4 条目；**分析时**只用 Llama-3.1-8B 自己的 V1 先验 P(C) ≥ 0.8 的条目。V1 的测法与第 3 步相同，每条 20 次，T=1。无先验对照不纳入分析，因为它没有先验方向。
- **系统**：neutral_roll（§10 中出现效应的那个系统）、codex、anthropic_api、llamaindex_facts。
- **用户**：sessions_v2 的前 96 个用户，与第 4 步完全相同的历史。
- **检查点**：0、2、4、8、12，和原框架实验一样，以便覆盖保持率从高到低的整个区间。
- **探针**：记忆状态由 gpt-oss-120b 和 gemma-3-27b 标注，只计两者一致的结果；信念探针由 Qwen3-235B 回答。答题和评判模型都与 §10 相同。

## 3. 预先登记的分析
- **不触底区间**：对每个系统和检查点，计算整体保持率 R（C 和 I 合并）。只用 0.2 ≤ R ≤ 0.8 的单元做主分析。
  - 这一筛选只依据合并后的 R，不依据 ΔR，所以不会偏向任何结论。
- **P5b.1（主检验）**：在 neutral_roll 的不触底单元中（各检查点合并），ΔR = R^C − R^I > 0，按用户聚类的自助法 95% 置信区间不含 0。
- **P5b.2**：把四个系统的不触底单元合并，同样要求 ΔR > 0 且置信区间不含 0。
- **P5b.3**（描述性）：报告不触底单元的 ΔF（往常识方向的翻转），以及每个检查点的 R^C、R^I。
- 如果某个系统没有任何不触底单元，就如实报告"该系统没有不触底区间"。
